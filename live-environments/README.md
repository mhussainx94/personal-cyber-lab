# Live USB Environments

Two portable, bootable USB environments are used alongside — but independently of — the triple-boot and VMware lab.

| Environment | Role |
|---|---|
| [Tails](tails/README.md) | Privacy-oriented portable live environment |
| [Kali Live](kali-live/README.md) | Portable Kali environment for testing/troubleshooting |

## Important Distinction

Neither Tails nor Kali Live is part of the VMware laboratory. Both boot independently from USB media on the physical laptop (or other hardware) and do not depend on the triple-boot installation or VMware Workstation.
