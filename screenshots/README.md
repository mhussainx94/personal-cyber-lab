# Screenshots

Evidence screenshots, organized by category.

```text
screenshots/
├── architecture/
├── networking/
├── dvwa/
├── metasploitable/
└── vulnerability-assessment/
```

## Naming Convention

```text
YYYY-MM-DD-description.png
```

Example:

```text
2026-09-28-dvwa-login.png
```

## Rules

- Only real screenshots from actual lab work are added here.
- No screenshot should contain credentials, tokens, private IP ranges outside the lab, or other sensitive information — review before committing (see [`SECURITY.md`](../SECURITY.md)).
- Directories are currently empty pending actual lab work.
